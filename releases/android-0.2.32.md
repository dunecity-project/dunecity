# Dune Legacy Android 0.2.32

Uses engine 1.0.855 and the same bundled mod content as desktop/browser 1.0.855.

- Include the new DuneCity faction Hospitals and Nuclear Plants, higher-detail
  special-building sprites and 39 matching sidebar portraits.
- Retain the existing asset-refresh checks so upgrades replace stale bundled
  graphics without resetting saves or gameplay settings.
- Show the matching Hospital/Church faction portrait in selected-building panels,
  including when the graphics skin changes while the panel remains open.
- Preserve Classic Desert as the default interface and keep Dune2R assets separate.

Multiplayer peers must use matching engine versions and mod content. Install this
APK over the previous version to retain application data. The release uses the
existing Android upgrade-signing identity; Android remains a separate download
from the desktop updater.
