# Dune Legacy Android 0.2.33

Engine 1.0.858; ARM64; Android 6.0 or newer.

- Hold at a map edge to scroll. Lift your finger to stop, including at the map
  boundary beside the sidebar. Zoom/view buttons remain usable.
- Hold a build icon still for 550 ms and release to remove one queued item.
  This never adds an item first. Tap normally to add one.
- Two-finger drag pans; pinch/spread changes zoom in 1.2x finger-distance steps.
  The map has finer 75%–400% zoom steps and larger minus/plus buttons for phones.
- Include the latest shared mobile controls and Dune2R rendering at intermediate
  zoom levels. Asset refresh continues to preserve saves and settings.

Install over the previous APK to retain app data. The upgrade-signing identity
is unchanged. Edge scrolling and queue removal were confirmed on an Android
phone. Multiplayer peers need engine 1.0.858 and matching mod content.
