# DuneCity 1.0.857

- Dune City builds for iPhone and iPad from the same source (see `IOS_PORT.md`).
  There is no App Store or TestFlight release yet; developers can install it on
  their own iPhone with `scripts/build-ios.sh`.
- New touch controls for phones and tablets (Android and iOS): drag two fingers
  to scroll the map, spread or pinch them to zoom, and tap with two fingers to
  right-click. On phones, tapping an enemy now attacks it and tapping the ground
  moves there (Options: Left-click orders). The unit order icons are larger, and
  tooltips no longer stay open over the map after a tap.
- Android and iPhone/iPad games now report their platform, so the public usage
  statistics count them separately from desktop.
- Windows, macOS, Linux and the browser version play exactly as in 1.0.856.

Network protocol 103, save version 9874. Older saves load. Multiplayer peers need
the same version.
