# DuneCity 1.0.879

## AI

- **A Construction Yard no longer stalls on a finished building with no safe site.** When enemy turrets covered every place the AI could put a finished building (seen with a Stadium), the yard held it indefinitely and built nothing else. After a minute it now places it on the legal site with the least enemy fire.

## Fixes

- **French voices no longer crash the game at launch** ("Cannot find 'FWORMY.VOC'", issue #129). The wormsign warning says "Warning" alone in French, as the French voice pack has only that half.
- **Linux start-up tries every render driver** (OpenGL, OpenGL ES, then software) and logs why each one failed, instead of stopping at "Couldn't find matching render driver" (issue #120). If none works, a message box lists the errors.

## Compatibility

- Multiplayer uses **protocol 135**. All players need 1.0.879; it cannot play with 1.0.878.
- The save format is unchanged (**9898**): 1.0.878 and 1.0.879 open each other's saves.
- Android has a separate version and publication process.
