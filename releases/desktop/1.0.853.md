# DuneCity 1.0.853

- Fix Linux startup when no usable audio device is available. The game now opens
  a silent mixer reliably instead of terminating; normal system audio is retained
  when available. Linux packages include ALSA, PulseAudio and PipeWire support.
- Keep packaged mod manifests byte-identical across Windows, Android, Linux,
  macOS and browser builds. Git checkout line-ending conversion previously made
  otherwise identical bundled content produce different multiplayer fingerprints.
- Preserve Classic Desert as the default interface and the existing sprite assets.

1.0.852 publication was held during final Android payload validation. This release
includes its audio fix and the additional packaging correction. Multiplayer peers
must use matching engine versions and mod content.
