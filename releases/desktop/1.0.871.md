# DuneCity 1.0.871

## Controls

1.0.870 moved the command keys to make room for a W/A/S/D camera. This release puts the classic keys back and keeps the newer commands as extras.

- **The classic command keys are back**: A Attack, S Stop, M Move, Q Patrol, H Hold, C Capture, D Carryall, R Repair, U Upgrade, P Place, G next Construction Yard and F next factory, with Ctrl+A, T and Ctrl+T for selections as before.
- **Every unit command now has a key**: E Guard, X Area Guard, B Ambush, N Hunt, K Retreat, Y Deploy MCV, V movement paths and Delete for a Devastator's self-destruct. The buttons' tooltips name them.
- All 33 commands can be changed under **Options > Hotkeys**.
- **W, A, S and D scroll the map only if you switch on "WASD camera"** under Options > Controls. It is off by default. While it is on, the commands on those keys need Shift, for example Shift+A to attack.
- If you never changed a key in 1.0.870 you get these keys automatically. Keys you chose yourself are kept. In such a profile seven of the newer commands can start without a key because their letters are in use: choose Defaults and then Apply to switch to the keys above.

## QuantBot

- No change to how any AI plays. On the same 216 late-campaign test games the campaign helper finished every game in exactly the same state as in 1.0.870.
- Tested and not adopted: a helper that repairs only its factories. It won 110 and 120 of 216 games against 129 for the 1.0.870 helper and earned about 11% less, because a damaged refinery unloads more slowly. The switch `CampaignHelperRepairFactoriesOnly` exists in the QuantBot config and is off.

## Known issues

- The keys have not been tried on German or French keyboard layouts.
- The Campaign AI and campaign helper known issues listed for 1.0.870 still apply.

## Compatibility

- Multiplayer still uses **protocol 126**. All players should run the same version.
- The save format is unchanged at **9886**.
- Android has a separate version and publication process.
