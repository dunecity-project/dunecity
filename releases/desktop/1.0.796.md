# Dune City 1.0.796

Five DuneCity maps now ship with the full release: 4 corners v1, DuneCity (192x192), test (256x256), city seige and Alkozeltser 4 Cities v1. They are available on clean desktop and browser installations through the DuneCity map selection.

- Pathfinding runs deterministic search slices across worker threads on supported desktop builds, with bounded work per simulation tick. Custom single-player QuantBot planning is spread across simulation ticks, and repeated spatial scans use shared fields to reduce stutter.
- Fully repaired units leave Repair Yards correctly, including units whose remaining damage is less than one HP. Carryall collection and ground release can finish instead of waiting indefinitely while repair costs continue.
- With **Override max units** enabled, Brutal QuantBot can build past its configured military-value target. A positive override retains the engine's unit-count limits; zero permits unlimited units. Starport deliveries wait when a positive limit is full and resume when capacity opens.
- Includes refreshed residential and industrial city artwork for all houses.

Existing saves remain loadable. Multiplayer protocol is 44; all players must update together. Saves, settings and user mods remain in the separate user folder.
