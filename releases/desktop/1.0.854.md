# DuneCity 1.0.854

- Upgrade 31 Dune2-skin special-building sprites from their original detailed
  artwork, retaining their existing map size and placement.
- Add seven missing faction buildings: Ordos, Fremen, Sardaukar and Mercenary
  Hospitals, plus Fremen, Sardaukar and Neutral Nuclear Plants. All eight factions
  now have all six special-building variants.
- Add 39 matching landscape portraits for construction menus and selected-building
  panels. All 72 zone/special-building packages now have dedicated portraits.
- Correct high-detail rendering for Hospital and Church civic overlays while
  preserving SimCity fallback, faction selection and fog behavior.
- Preserve existing R/C/I artwork, Industrial smoke animations, game rules and
  logical building footprints. Existing asset-refresh checks install the new
  bundled artwork when upgrading.

Windows, macOS, Linux, browser and Android use engine 1.0.854. Android is versioned
separately as 0.2.32. Multiplayer peers must use matching engine versions and mod
content. Dune2R artwork and scaling are unchanged by this release.
