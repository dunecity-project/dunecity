# DuneCity 1.0.858

- Choose finer map zoom steps from 75% to 400%, using the in-game minus/plus
  buttons or mobile pinch gestures. Dune2R high-detail graphics work at every
  step, and selection and orders follow the scaled map correctly.
- On Android and iOS, hold at the map edge to scroll and lift to stop. The edge
  beside the sidebar works too; view buttons and dialogs are excluded.
- Hold a production icon still for about half a second and release to remove
  one queued item, without adding an item first. Ordinary taps still add items.
  Physical mouse right-click keeps its existing pause-then-cancel behavior.
- Retain two-finger panning, pinch zoom, box selection and left-click orders.
  Touch detection also works when cursor visibility is forced on or off.

Android 0.2.33 uses this engine. Existing app data and saves are retained during
upgrade. Multiplayer peers need matching engine versions and mod content.
iPhone/iPad TestFlight distribution remains managed separately.
