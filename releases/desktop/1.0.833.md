# Dune City 1.0.833

A robustness release. Every test build now runs with memory and undefined-behaviour checking, and the problems it found are fixed.

- Long games no longer make QuantBot's choice between Devastators, Sonic Tanks and Deviators unreliable. With a lot of combat history the score that ranks them overflowed and could rank them wrongly; it now stays a proper average of what each unit has achieved.
- Game graphics, animations and mentat texts are read safely regardless of how their data is laid out in the original files.
- AdLib music is generated the same way on Apple Silicon as on Intel, where negative waveform positions used to be clamped instead of wrapping.
- Tutorial hints no longer misfire for items whose numbers are above 31.
- A malformed house number in a multiplayer lobby packet is now rejected cleanly.

Existing saves remain loadable. Multiplayer protocol is **70**: all peers must update together. Saves, settings and user maps remain in the separate user folder.
