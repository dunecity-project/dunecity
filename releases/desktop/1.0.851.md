# DuneCity 1.0.851

- **Classic Desert interface:** textured sandy buttons, crisp retro pixel
  lettering, dark-orange engraved labels and the classic desert backdrop.
  Classic Desert is the default for new profiles and profiles without a saved
  UI skin preference.
- **Choose your interface:** Settings retains Modern and Lapis Enamel as
  alternatives. Existing saved skin choices are respected; select Classic
  Desert explicitly if you previously saved another style.
- **Readable controls:** high-contrast colors remain available, and text that
  the retro font cannot display uses the original font instead.
- Includes the performance, AI, campaign and multiplayer updates from
  1.0.850. Interface skins do not change gameplay zoom, Native 1:1 resolution,
  Dune2R world scaling, game rules or sprite packs.
