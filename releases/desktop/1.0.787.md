# Dune City 1.0.787

This release fixes multiplayer joins for players who have not previously downloaded the host's map and mod.

- Fresh guests can receive the map and then resolve its pinned mod without getting stuck while receiving game setup. Map integrity and dependency checks remain enforced.
- Includes the DuneCity graphics integration: 34 building and zone skin packages, authored zone portraits, and skin selection in campaign and co-op setup.
- Refreshes changed bundled graphics reliably, including artwork updates that retain the same version and file size.

Internet hosts continue to collect and publish map revisions when setting up their lobby. Guests retain received maps locally. LAN games do not publish maps.

This fix does not change the multiplayer protocol or save format. Saves, settings and user mods remain in the user folder.
