# DuneCity 1.0.852

- **Linux audio startup fixed:** portable Linux packages now include ALSA,
  PulseAudio and PipeWire backends instead of relying on legacy OSS audio.
- **Safe silent fallback:** if a sound device or audio backend cannot open,
  the game correctly initializes a silent mixer rather than crashing while
  retrying the failed device. Restart the game to retry system audio.
- **Package checks strengthened:** test normal audio selection, explicitly
  selected dummy audio and recovery from an unavailable driver on the game
  binary and the packaged Linux TGZ/AppImage. Fatal startup dialogs now fail
  portable-package checks instead of looking like a successful running game.
- Retains the Classic Desert, Lapis Enamel and Modern interfaces, artwork and
  gameplay from 1.0.851. This update does not change saves or game rules.

Audio-backend and silent-recovery checks run without physical sound hardware;
actual device playback depends on the host's working audio setup.
