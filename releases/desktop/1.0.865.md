# 1.0.865 Linux renderer test candidate

Unpublished issue #120 test build. This is not an official multi-platform release.

- Linux startup recovers with a software renderer when acceleration cannot initialize,
  while still requiring target-texture support and respecting SDL driver preferences.
- Linux builds explicitly include desktop OpenGL/EGL prerequisites and use a fresh SDL
  dependency cache to avoid restoring earlier graphics-deficient builds.
- SDL IBus input support now explicitly includes its required D-Bus dependency, and
  Linux CI installs the documented desktop development headers.
- New video diagnostics verify backend availability, accelerated and software rendering,
  target-texture output, and failure recovery in the executable and portable packages.

No gameplay, network protocol, or saved-game format changes are intended. The candidate
must be tested on the affected Linux Mint/NVIDIA installation; virtual-display checks do
not certify physical GPU compatibility or graphics performance.
