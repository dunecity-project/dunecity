# DuneCity 1.0.865

## Transparent civic buildings

- Police Stations, Nuclear Plants, Stadiums and Airports now retain terrain
  beneath their transparent corners instead of exposing black empty areas.
- The fix applies to all houses and zoom levels, including DuneCity house skins
  used while the global Dune2R visual fade is off. Sprite artwork, placement
  footprints and opaque vanilla building rendering remain unchanged.

## Linux startup recovery

- Linux startup recovers with a software renderer when acceleration cannot initialize,
  while still requiring target-texture support and respecting SDL driver preferences.
- Linux builds explicitly include desktop OpenGL/EGL prerequisites and use a fresh SDL
  dependency cache to avoid restoring earlier graphics-deficient builds.
- SDL IBus input support now explicitly includes its required D-Bus dependency, and
  Linux CI installs the documented desktop development headers.
- New video diagnostics verify backend availability, accelerated and software rendering,
  target-texture output, and failure recovery in the executable and portable packages.

No gameplay, network protocol or saved-game format changes from 1.0.864.
Protocol remains 109 and save format remains 9879. The Linux recovery path
requires a software renderer with target-texture support; explicit SDL driver
preferences are preserved.
