# DuneCity 1.0.855

- Upgrade 31 Dune2-skin special-building sprites from their detailed artwork,
  retaining their existing map size and placement.
- Add seven missing faction Hospitals/Nuclear Plants and 39 matching landscape
  portraits. All eight factions have all six special-building variants; all 72
  zone/special packages include dedicated portraits.
- Hospital and Church properties now display their own faction portraits. Open
  properties panels also refresh correctly when a civic overlay or graphics skin
  changes; SimCity keeps its live preview.
- Retain high-detail Hospital/Church map rendering, native fallbacks, existing
  R/C/I artwork, Industrial animations, saves and gameplay rules. Upgrades refresh
  the bundled artwork automatically. Dune2R assets and scaling remain separate.

Includes the artwork from the unpublished 1.0.854 candidate with the final civic
portrait integration. Windows, macOS, Linux, browser and Android use engine
1.0.855; Android is versioned separately as 0.2.32. Multiplayer peers need matching
engine versions and mod content.
