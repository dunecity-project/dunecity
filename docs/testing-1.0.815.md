# Testing artwork in 1.0.815

## Dune2R downloads and remastered Infantry

1. Open **Custom Game**, select **Dune2R**, and wait for the artwork preparation panel. A clean profile downloads six packs, approximately 384 MB, from GitHub. Retry resumes after a connection failure; Cancel returns to setup.
2. Once preparation completes, continue to the map and player selections. Choosing Dune2R again uses verified cached artwork. Complete cached artwork remains available when the catalog cannot be reached offline.
3. For an animation preview, open **Editors → Asset Editors → Dune2R → Open Editor**, select **Harkonnen Infantry Remastered**, and inspect walking, combat, Return to Idle, collapse and aftermath.
4. To exercise the artwork during a game, use **Harkonnen Soldier** units. Harkonnen WOR Troopers use different artwork. A Harkonnen player ordinarily needs a captured Barracks or a prepared map with Soldiers/Barracks; changing only the player house does not turn Troopers into Soldiers.
5. During the match, compare the **Dune2R / Classic** graphics toggle and zoom. Terrain, buildings and units scale together; menus and the sidebar retain their size.

For the prepared local test map, choose **MP User Maps → 2P - 32x32 - PR89 Infantry Test**, Harkonnen human / Team 1 and Atreides QuantBot Easy / Team 2. The map is supplied in the separate local test kit, rather than the public installer.

## DuneCity special-building artwork

Choose **Custom Game → DuneCity**, the bundled **DuneCity** map, **Rebels**, and **Skin Dune2**. Inspect Airport, Stadium and Nuclear Plant; Hospital and Church appear as residential civic overlays. Compare **Skin SimCity**. Dune2 is the city skin; Dune2R is a separate game mod.

Saves, settings, user maps and downloaded artwork remain in the separate user folder when the application is upgraded. Shared mod versions keep their pinned content.
